# Submission packaging

## Folder layout

| Location | Purpose |
|----------|---------|
| `website/` | Day-to-day development — double-click `index.html` to run |
| Portfolio ZIP (you create later) | Evidence Log xlsx, screenshots, reflection, **and a copy of `website/`** |

## Suggested ZIP for Aula (when ready)

```
YourName_ProfessionalEnglish_Portfolio.zip
  website/          ← copy of this project’s website folder
  evidence/         ← EV-001, EV-002, … PNG screenshots
  Database Evidence Log (1).xlsx
  Reflection_1000words.docx
  References.pdf    (optional if included in reflection)
```

Website-only ZIP (for sharing the product):

```
YourName_VocabHub_website.zip
  (contents of website/)
```

Teachers double-click **`START HERE - Double-click to Open Website.html`** at the **top level** of the folder (not inside `website/`).
