# Product Pitch Outline — ByteBuddy Vocab Hub (≈5 minutes)

**Audience:** First-year Computer Science / AI students  
**You on camera + screen recording of the live website**  
**Language:** Professional English (bullet points below — turn into your own spoken sentences; do not read verbatim)

---

## 1. Hook — problem (0:00–0:45)

- Open with a relatable moment: *“Week three, you open a PDF, and ten new terms appear in one lecture — algorithm, gradient, repository…”*
- **Problem:** CS vocabulary arrives fast; highlighters and random notes do not help you **find**, **review**, or **group** words by course topic.
- **Cost:** You recognise words in class but cannot use them confidently in labs, reports, or exams.

**Visual:** Your face to camera, then cut to a messy notes slide (optional) → transition to START HERE file.

---

## 2. Solution — what ByteBuddy is (0:45–1:30)

- **ByteBuddy Vocab Hub** = a **purpose-built vocabulary database** for CS freshmen, not a generic dictionary app.
- **52 single-word entries**, organised into **four modules**: Programming, AI & ML, Maths & Logic, Lab & Tools.
- Each entry: English headword, **Chinese meaning** (for first-stage learning), English definition, example sentence, pronunciation (Listen), review status.
- **Offline:** double-click **START HERE - Double-click to Open Website.html** — no install.

**Visual:** Open START file → Browse page → point to module pill + Chinese line on one card.

---

## 3. Live demo — “day in the life” (1:30–3:30)

Walk one realistic study session (this is the core of the pitch):

1. **Browse + filter (CL-002)**  
   - Search `debug` or filter **Programming**.  
   - *Benefit:* “Find lab vocabulary in seconds.”

2. **Table view (evidence / structure)**  
   - Switch to Table — show columns, **中文 before English**.  
   - *Benefit:* “See the whole database like a proper data table — good for weekly review.”

3. **Track progress (CL-003)**  
   - Mark a word **Learning** with N/L/M.  
   - Filter by **Learning**.  
   - *Benefit:* “You always know what to revise tonight.”

4. **Review mode (CL-008)**  
   - Open **Review** → card shows English only → **Reveal** → Chinese + English + example.  
   - *Benefit:* “Self-test like flashcards, but tied to your CS modules.”

5. **Export (CL-004) — optional if time**  
   - Mention CSV export for backup or printing — 10 seconds max.

**Visual:** Smooth mouse moves; zoom browser to 125% so text is readable on recording.

---

## 4. Why this beats alternatives (3:30–4:15)

| Generic apps | ByteBuddy |
|--------------|-----------|
| Random word lists | **Module-aligned** CS vocabulary |
| No review workflow | **New → Learning → Mastered** + filters |
| Needs account / internet | **Offline ZIP**, local progress |
| Dictionary-only | **Bilingual + example in CS context** |

- Mention you **built and iterated** the system (Evidence Log) — shows it is maintainable, not a one-off slide deck.

---

## 5. Limitations — honest + fix (4:15–4:40)

- Review progress is **saved in this browser only** (localStorage) — you added **export JSON** and discussed future sync in reflection.
- **TTS** quality varies by browser — not a replacement for a teacher’s pronunciation.
- You will **keep adding words** each semester as courses progress.

**Why say this:** Brief rewards acknowledging limitations + how you address them.

---

## 6. Close — call to action (4:40–5:00)

- **Future picture:** “Imagine every CS freshman opening the same hub on day one — fewer panics in English-medium labs.”
- **Ask:** “Try the START file this week; filter one module that matches your current course and mark five words as Learning.”
- **Thank you** + smile; hold on Browse dashboard showing **52 words**.
